Featured project

AI Team Workspace · Teamspace

macOS 桌面应用。把 Claude Code、Codex、MiniMax Code、Gemini CLI 等组成固定岗位（Leader / 产品 / 前端 / 后端 / QA）的开发团队。

A macOS desktop app that organises Claude Code, Codex, MiniMax Code, Gemini CLI and others into a team with fixed roles (Leader / PM / Frontend / Backend / QA).

岗位 ≠ 工具 ≠ 模型Role ≠ tool ≠ model 任务派给岗位，岗位可随时换绑到其他 Harness 或模型，并自动继承上下文。 Work goes to roles; a role can be rebound to another harness or model and keeps its context.
ACP + MCPACP + MCP 通过 ACP 协议驱动各家 CLI；MCP 工具箱让 Leader 自己拆任务、派工和验收。 Drives each CLI over ACP; an MCP toolbox lets the Leader split, assign and review tasks itself.
每次执行一个 worktreeOne worktree per run 隔离执行、逐文件 diff 验收，通过后才合入基线分支；退回可续接会话。 Isolated runs, per-file diff review, merged only after approval; rejected runs resume the same session.
人有最终控制权Humans stay in control 超出岗位权限的请求、换绑和合并主分支，都由人来拍板。 Out-of-scope permissions, rebinding and merges to main always need a human decision.

我的工作方式

How I work

可用优先、纵向切片、用中迭代。这个项目本身就由一支 AI 团队开发：Claude 担任总指挥，按任务强度把工作派给 Opus、Sonnet、Haiku 和 MiniMax，我负责最终决策与验收。

Usable first, vertical slices, iterate through real use. The project itself is built by an AI team: Claude leads and routes work by difficulty to Opus, Sonnet, Haiku and MiniMax, while I make the final calls and sign off.
